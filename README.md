# Среда для сайтов с Codex · версия 2

Откройте START.html двойным кликом: там маршрут работы и готовый пример «Денсио».

## Ваш первый сайт

1. Распакуйте архив. Внутри одна папка starter. Для каждого нового сайта делайте её отдельную копию и называйте по проекту.
2. Добавьте эту папку как локальный проект в Codex. Она должна быть основной папкой: прямо в ней лежат AGENTS.md и BRIEF.md.
3. Начните локальную задачу: «Привет, начинаем. Прочитай AGENTS.md и проведи меня по брифу сайта».
4. Опишите проект, положите материалы в materials и пришлите 2–3 референса с пояснениями. Если направление уже выбрано, сразу скажите об этом.
5. Codex заполнит BRIEF.md, REFERENCES.md, DESIGN.md и план изображений в materials/ASSETS.md. Если нужна генерация, начните с одного главного изображения.
6. Напишите: «Собери главную по брифу и DESIGN.md. Используй подготовленные материалы. Открой результат в браузере и проверь на компьютере и телефоне».
7. Посмотрите всю страницу и передайте замечания одним списком. После исправления попросите обновить REVIEW.md и HANDOFF.md.

## Что уже работает

examples/densio/index.html — готовая демонстрационная страница. Открывается с диска, включает локальные изображения, шрифты, три этапа по прокрутке и движение от курсора. examples/densio/WALKTHROUGH.md объясняет принятые решения; WORKBOOK.html показывает бриф, визуальное направление и результаты проверки.

Это отдельный пример. Ваш index.html ещё не создан: Codex соберёт его из вашего брифа, не подставляя медицинский текст и оформление примера.

## Что делает среда

Три скилла ведут работу от брифа до приёмки. В папке лежат шаблоны для референсов, визуального направления, изображений, страниц и проверки. В них нужно зафиксировать конкретные решения вашего проекта. Удачный результат зависит от этих решений, материалов и обратной связи — архив не гарантирует дизайн одним сообщением.

Глобальные плагины, личные настройки автора и API-ключи не нужны. Для генерации нужен доступный встроенный инструмент Codex; расходуются лимиты вашего плана. Если его нет, используйте свои изображения. Браузерную проверку выполняйте доступным средством Codex; непроверенное должно быть отмечено в отчёте. Внешние платные сервисы автоматически не подключаются.

Публикация, домен и рабочая отправка заявок — отдельный этап. В демонстрационной форме ничего не отправляется.

Скрытая .agents содержит скиллы. На Mac показать её можно через Command + Shift + точка; Codex читает её и без этого.
